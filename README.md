# 555 Pocket Piano 🎹⚡

An ultra-compact, completely analog keyboard synthesizer powered by the iconic NE555 timer IC. No microcontrollers, no firmware, and no code—just pure analog oscillation turned into playable musical tones!

## 📌 Project Overview

The **555 Pocket Piano** is a handheld electronic musical instrument designed using EasyEDA. Operating as an astable multivibrator, the circuit produces a distinct audio frequency for every key pressed. By using a series-connected resistor divider ladder, pressing each tactile push switch dynamically alters the RC timing loop, instantly shifting the output pitch played through an onboard speaker or piezo transducer.

### ✨ Key Features

* **100% Analog Design:** Zero lines of code or complex digital hardware.

* **6-Key Tactile Keyboard:** Standard push-button layout for responsive, clicky playability.

* **Wide Input Voltage:** Operates reliably between **5V and 9V** (compatible with a 9V battery or USB power).

* **DC Output Decoupling:** Integrated electrolytic capacitor eliminates DC offset to protect the transducer and provide crisp square-wave tones.

* **Compact Form Factor:** Designed for easy hand assembly with through-hole components.
